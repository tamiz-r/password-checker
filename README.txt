PASSWORD STRENGTH CHECKER AND GENERATOR

Files:
- index.html: page structure and controls
- style.css: user interface styling and responsive layout
- script.js: strength checking, password generation, shuffle, show/hide and copy features

How to run:
1. Extract the ZIP file.
2. Open the password-strength-checker folder.
3. Open index.html in a modern web browser.
4. For best clipboard support, run through localhost or HTTPS.

No external libraries or dependencies are required.

Note:
The strength checker uses simple character/length heuristics. It is an educational indicator,
not a complete password-security audit. Generated passwords use the browser's Web Crypto API.
